NovaCure Pharma — TRAINING DOCUMENT (FICTIONAL / SYNTHETIC)
SOP-INTAKE-TRIAGE-HITL-102: Intake Fields, Status Workflow, and HITL Close
Version 2.0 | Effective 2026-04-05 | Classification: Synthetic / Non-Clinical

1. Purpose
Document mandatory intake fields, allowed status transitions, and Human-in-the-Loop (HITL) close approval for the fictional NovaCure tracker so reviewers and the agent share one grounded source of truth.
2. Mandatory fields
Report type; product name; batch/lot LOT-#####; date received; reporter type; description. Suspected Adverse Event rows additionally require event description and event onset date — still without real PII.
3. Status machine
New → In Review (allowed). In Review → Closed (requires HITL approve-close). New → Closed (illegal). Closed is terminal for this prototype. Reject-close returns the case to In Review.
4. Roles
Operator: create intake, start review if permitted. Reviewer: triage and request close. Approver: approve or reject pending close and agent HITL interrupts. Admin: all of the above plus document ingest.
5. Audit expectations
Every create, status change, HITL decision, document upload/delete, and agent tool invocation must leave an audit event in the local audit SQLite database.
