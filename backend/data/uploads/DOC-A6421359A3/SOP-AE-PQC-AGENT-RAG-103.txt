SOP-AE-PQC-AGENT-RAG-103: AE/PQC Handling, Agent Guardrails, and Knowledge Retrieval
Version 2.0 | Effective 2026-04-10 | Classification: Synthetic / Non-Clinical

1. Purpose
Combine Suspected Adverse Event (AE) intake notes, Product Quality Complaint (PQC) handling, agent router guardrails, and hybrid RAG expectations into one long training document for upload demos.
2. AE handling (fictional)
Capture event description and onset date. Do not assess causality. Do not recommend treatment. Do not decide reportability. Example training case: REF-2026-0002 CardioSafe 10mg LOT-12045 dizziness report.
3. Agent intents
Greeting → direct reply. SOP/history question → Hybrid RAG. New submission → submit_intake_report. Status change → update_status with validation. Close from In Review → HITL interrupt until approver resolves.
4. Retrieval pipeline
BM25 + dense retrieval fused with Reciprocal Rank Fusion (k=60), then cross-encoder / configured rerank. Drop weak chunks below the configured threshold. Pass only top grounded snippets to generation. If nothing passes, return insufficient evidence — never invent SOPs.
5. Circuit breaker
Repeated identical invalid tool arguments (for example lot=ABC failing LOT-##### validation) open the breaker after consecutive failures and halt the agent loop for that turn.
